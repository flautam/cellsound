Help & accessibility

How to use Cellsound with a screen reader, keyboard, and larger text. We design for WCAG 2.1 Level AA.

How to use with VoiceOver (Mac)

  1. Turn VoiceOver on with Command + F5 (or Siri: “Turn on VoiceOver”).
  2. Open Cellsound in Safari or Chrome, then press Control + Option + A to start reading, or Control + Option + Right Arrow to move item by item.
  3. Use the Rotor (Control + Option + U) to jump by headings, links, form controls, or landmarks. Each page has a header, step navigation, and main region.
  4. Press Tab for the “Skip to main content” link, then Enter to jump past the header.
  5. On Upload, choose files with the file control, set calibration if you want, then activate “Start processing.” Status messages update live while frames track.
  6. On Analysis settings, move the Point of Audio with the arrow buttons or by dragging; VoiceOver announces the new position in the preview label.
  7. On Overview, each video is a toggle button. VoiceOver says whether it is selected. After sorting, a status line says how many videos matched; matches are also labeled “Match.”
  8. On Detailed analysis, pick a chunk from the list, then “Play this chunk” to hear it. Volume is separate from system VoiceOver speech—lower app volume if speech is hard to hear.
  9. On Export, choose which videos and which file types, then download the zip.

How to use with NVDA (Windows)

  1. Install NVDA, then start it. Browse Cellsound in Firefox or Chrome.
  2. Press Insert + Down Arrow to say all, or use arrow keys to move by line. Press H / Shift + H for next/previous heading.
  3. Press D for landmarks (header, navigation, main). Press B for buttons, F for form fields, K for links.
  4. Tab reaches “Skip to main content,” then interactive controls in order. Focus outlines stay visible.
  5. Live regions announce tracking progress, sort results, and playback status without moving focus.
  6. If NVDA speech overlaps Cellsound audio, pause NVDA with Shift, or lower “App volume” on Detailed analysis.
  7. For the Point of Audio, use the on-screen nudge controls if dragging is awkward with the mouse pointer.

Text size, contrast, and motion

  • Open Text size & contrast in the header. Choose Standard, Larger, or Largest text.
  • Choose Light, Dark, or High contrast. High contrast uses yellow on black for strong edges.
  • Check Pause animations if motion is distracting. The site also respects your system “reduce motion” setting.
  • Browser zoom (for example 200–400%) should reflow content into a single column without cutting off buttons or labels.

WCAG 2.1 Level AA

We aim to meet the W3C WCAG 2.1 Level AA criteria that apply to this app. In practice that includes:

  • Keyboard access to controls, with a visible focus indicator
  • Skip link, page titles, headings, and labeled form fields
  • Text alternatives for scientific frames (behavior descriptions as image alt text)
  • Status updates that screen readers can hear (live regions)
  • Contrast themes and resizable text that reflows
  • Not relying on color alone for sort matches (count text + “Match” labels)
  • Sonification and plain-language descriptions as non-visual ways to understand motion

Known limits: silent overview videos do not yet include a separate audio-description track; exported WAV files do not yet ship a timed transcript. Text summaries and chunk sound still carry the meaning.
