Before you start

We use sound panning (left and right speakers) to help distinguish cell movement. Headphones are recommended.

Make it comfortable

  • You can customize text size & contrast using the settings the top of every screen.
  • Pressing Esc stops all sound.
  • Toggle Pause animations under Text size & contrast to stop all movement.
